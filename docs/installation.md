# Installation

## Stable release

To install shape2graph, run this command in your terminal:

```
pip install shape2graph
```

This is the preferred method to install shape2graph, as it will always install the most recent stable release.

If you don't have [pip](https://pip.pypa.io) installed, this [Python installation guide](http://docs.python-guide.org/en/latest/starting/installation/) can guide you through the process.

## From sources

To install shape2graph from sources, run this command in your terminal:

```
pip install git+https://github.com/bhattarainemi/shape2graph
```
